Formulaire de demande de devis

Le formulaire de la page Contact collecte les informations suivantes :

  • votre nom (obligatoire) ;
  • votre adresse e-mail (obligatoire) ;
  • votre numéro de téléphone (facultatif) ;
  • le type de besoin (obligatoire) ;
  • le délai souhaité (facultatif) ;
  • un budget indicatif (facultatif) ;
  • votre message (obligatoire) ;
  • votre accord pour être recontacté au sujet de votre demande (case à cocher obligatoire).

Si vous arrivez depuis la fiche d'une solution du catalogue, le nom de cette solution est ajouté à la demande. Le formulaire envoie aussi la langue de la page et le temps passé sur le formulaire, que le serveur utilise pour repérer les envois automatiques.

Pourquoi

Ces informations servent à répondre à votre demande.

Comment la demande est transmise

Sur le site hébergé par Vercel, la demande est envoyée à une fonction serveur, qui la transmet par e-mail au studio grâce au service Resend. Le site ne l'enregistre dans aucune base de données. Elle reste dans la boîte e-mail du studio le temps de traiter votre demande.

Sur la copie hébergée par GitHub Pages, ou si l'envoi direct échoue, le site n'envoie rien : votre messagerie s'ouvre avec un message pré-rempli, et la demande part depuis votre messagerie quand vous l'envoyez.

Pour limiter le spam, la fonction serveur garde en mémoire votre adresse IP afin de compter les demandes (5 au plus toutes les 10 minutes). Elle ne l'enregistre pas et ne l'ajoute pas à l'e-mail. Les journaux du serveur ne contiennent qu'un code technique d'erreur, sans donnée personnelle.

Questionnaire « Trouver ma solution »

Le calcul de la recommandation se fait dans votre navigateur. Rien n'est envoyé ni enregistré.

Vos réponses apparaissent dans l'adresse de la page. Elles peuvent donc rester dans l'historique de votre navigateur, et être transmises à quelqu'un si vous partagez le lien.

Si vous passez ensuite au formulaire de devis depuis les résultats, votre besoin, votre délai et votre budget sont repris dans l'adresse de la page Contact pour pré-remplir le formulaire. Ils ne sont envoyés que si vous envoyez la demande.

Cookies et stockage

Ce site n'utilise aucun cookie, ni localStorage, ni sessionStorage. Il ne dépose rien dans votre navigateur : même la langue se choisit par l'adresse de la page.

Il n'utilise ni outil de mesure d'audience ni publicité.

Services tiers

Ces services interviennent dans le fonctionnement du site. Leurs politiques de confidentialité décrivent ce qu'ils font des données qu'ils reçoivent.

  • Google Fonts : les polices du site sont chargées depuis les serveurs de Google, qui reçoivent l'adresse IP du visiteur. Politique de confidentialité — Google (nouvel onglet)
  • Vercel : hébergement du site et de la fonction serveur qui reçoit les demandes de devis. Votre navigateur lui envoie ses requêtes, dont votre adresse IP. Politique de confidentialité — Vercel (nouvel onglet)
  • GitHub Pages : hébergement de la copie du site. Votre navigateur lui envoie ses requêtes, dont votre adresse IP. Politique de confidentialité — GitHub (nouvel onglet)
  • Resend : service qui envoie par e-mail les demandes de devis au studio. Il reçoit le contenu de la demande. Politique de confidentialité — Resend (nouvel onglet)
